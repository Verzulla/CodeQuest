Зачем это нужно

Генератор отдаёт значения по одному и не держит весь список в памяти — можно пройти даже по файлу в гигабайт.

PYTHONЗапустить
def countdown(n):
while n > 0:
yield n
n -= 1
print(list(countdown(3)))
[3, 2, 1]
Частая ошибка: генератор можно пройти только один раз.

Как работает yield

Функция с yield ставится на паузу и продолжает с того же места при следующем запросе.

PYTHONЗапустить
gen = countdown(2)
print(next(gen))
print(next(gen))
