# Макеты редизайна (стиль B)

Согласованы 30.09.2026. Открывать в браузере прямо из репозитория — совы берутся из `static/img/owls/`.

| Файл | Что внутри |
|---|---|
| `final.html` | задание, верный ответ, дорожки (зигзаг и список), финал урока, «сердечки закончились»; десктоп: дорожка, задание, финал |
| `screens2.html` | повторение, награды, статистика, настройки, «О приложении» — варианты A/B (выбраны: A, B, A, B, B) |
| `desktop2.html` | выбранные варианты этих экранов на десктопе |
| `auth-theory.html` | вход/регистрация (выбран A) и первые варианты теории |
| `theory.html` | итоговая теория урока: шаги по разделам, «одной страницей», десктоп |
| `owl-animated.html` | векторная сова и анимации |

Решения: «Уроки по порядку» → «Открыть все уроки» (включено = всё открыто); теория — шаг = раздел `##` без сокращений, шпаргалка — последним шагом и кнопкой; сова только на первом шаге.
