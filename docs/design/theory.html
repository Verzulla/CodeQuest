Телефон — одной страницей

Итераторы

Зачем это нужно

Цикл for умеет перебирать списки, строки, словари, файлы, range. Всё это работает через один механизм — итераторы. Поняв его, ты поймёшь, как устроены генераторы, почему файл можно читать построчно и почему некоторые объекты можно перебрать только один раз.

Термины

  • Итерируемый объект (iterable) — то, что можно перебрать в for: список, строка, словарь, файл, range.
  • Итератор (iterator) — объект, который выдаёт элементы по одному и помнит, где остановился.
  • iter(x) — получить итератор из итерируемого объекта.
  • next(it) — взять следующий элемент. Когда элементы кончились — исключение StopIteration.

iter и next

PYTHONИзменить▶ Запустить
it = iter("abc")
print(next(it))
print(next(it))
print(next(it, "конец"))
print(next(it, "конец"))
  • Каждый next сдвигает итератор на один элемент.
  • next(it, значение) — вместо StopIteration вернуть значение по умолчанию.
  • Вывод: a, b, c, конец.

Итератор одноразовый

PYTHONИзменить▶ Запустить
it = iter([1, 2, 3])
print(list(it))
print(list(it))
  • list(it) забрал все элементы. Итератор «исчерпан» — второй раз он пуст.
  • Сам список при этом можно перебирать сколько угодно: каждый for создаёт новый итератор.
  • Вывод: [1, 2, 3], [].

Итерируемое и итератор — разные вещи

PYTHONИзменить▶ Запустить
nums = [1, 2]
it = iter(nums)
print(iter(it) is it, iter(nums) is iter(nums))
print(hasattr(nums, "__next__"), hasattr(it, "__next__"))
  • У итератора есть метод __next__, у списка — нет.
  • iter(итератор) возвращает его самого, а iter(список) каждый раз создаёт новый итератор.
  • Вывод: True False, False True.

Как на самом деле работает for

PYTHONИзменить▶ Запустить
it = iter(["x", "y"])
while True:
try:
item = next(it)
except StopIteration:
break
print("элемент", item)
  • for item in items: — это iter(items) один раз, затем next в цикле до StopIteration.
  • Вывод: элемент x, элемент y.

Продолжить с середины

PYTHONИзменить▶ Запустить
it = iter(["id,name", "1,Аня", "2,Боря"])
header = next(it)
for row in it:
print(row)
print("заголовок:", header)
  • Забрали первый элемент вручную, for продолжил с того места, где остановился итератор. Так пропускают заголовок CSV.
  • Вывод: 1,Аня, 2,Боря, заголовок: id,name.

Итог

  • iter(x) — итератор; next(it) — следующий элемент; конец — StopIteration.
  • next(it, default) — без исключения.
  • Итератор одноразовый; итерируемый объект (список) — многоразовый.
  • for = iter + next + обработка StopIteration.
