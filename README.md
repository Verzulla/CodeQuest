# 🦉 CodeQuest

Учим Python в игровом формате, как в Duolingo: дорожка уроков, XP и уровни,
серия дней, сердечки, дневная цель, награды за модули и темы, достижения,
работа над ошибками и статистика. Весь прогресс хранится в SQLite (`data/codequest.db`).

## Запуск

```bash
./run.sh
```

Открой http://127.0.0.1:8765. При первом запуске создастся окружение и загрузится стартовая тема
«Python: основы» из `content/`.

## Как устроено

| Папка | Что внутри |
|---|---|
| `app/db.py` | схема SQLite |
| `app/game.py` | XP, уровни, streak и заморозки, сердечки, награды, достижения |
| `app/runner.py` | запуск кода ученика в отдельном процессе с тестами и таймаутом |
| `app/content.py` | импорт/экспорт JSON-пакетов, карта пути |
| `app/main.py` | HTTP API |
| `app/cli.py` | `validate` / `import` / `export` контент-пакетов |
| `static/` | фронтенд без сборки (ES-модули) |
| `content/` | контент-пакеты JSON (9 тем, 250 заданий) и `ORDER` — порядок тем |
| `content/src/` | исходники пакетов на Python: `<тема>.py` — задания, `theory_<тема>.py` — подробная теория и «Проверь себя» (`build.py` собирает всё в JSON) |
| `tests/` | автотесты (`.venv/bin/python -m pytest`) |

## Контент

Два равноправных способа, оба пишут в одни и те же таблицы:

1. **Админка** — раздел «Контент» в приложении.
2. **JSON-пакет** — например, сгенерированный Claude:
   ```bash
   .venv/bin/python -m app.cli validate content/my-topic.json   # проверить эталоны и вывод
   .venv/bin/python -m app.cli import   content/my-topic.json   # загрузить
   ```
   или через кнопку «Импорт JSON» в админке.

Пакеты из репозитория описаны на Python в `content/src/` (так удобнее писать код заданий).
Пересобрать и загрузить тему:

```bash
.venv/bin/python -m content.src.build oop       # content/src/oop.py → content/oop.json
.venv/bin/python -m app.cli import content/oop.json
```

Каждый элемент имеет стабильный `slug`, прогресс привязан к нему — повторный импорт
обновляет задания, но не сбрасывает прогресс. Импорт никогда ничего не удаляет.

### Теория урока

- `theory` — краткая теория перед заданиями.
- `theory_full` — подробный урок (markdown). Блоки ```` ```python ```` получают кнопки «Запустить» и «Изменить»,
  а `validate` запускает каждый такой пример — пакет с упавшим примером не пройдёт проверку.
  Блоки ```` ```py ````, ```` ```yaml ````, ```` ```bash ```` только подсвечиваются.
- `quiz` — вопросы «Проверь себя»: `[{"q": "...", "options": ["...", "..."], "answer": 0, "explain": "..."}]`.

### Типы заданий

- `code` — ученик пишет код; проверяется функциями `test_*` из поля `tests`.
  В тестах доступны имена из кода ученика, `OUTPUT` (всё напечатанное) и `capture(f, *args)`.
- `output` — ученик читает `code` и вводит, что он выведет (`expected_output`).

## Резервная копия

Скопируй `data/codequest.db` — это и есть весь твой прогресс.
